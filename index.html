Standing rules

  • Insulin — 0 IU by default. Opens only if fasting glucose trends >110–120 mg/dL. First-ever dose 2–3 IU with meter, 5 IU ceiling, never at night.
  • Thyroid — zero. Euthyroid (TSH 1.72 / fT3 3.06). EUTHYROX + CYTOMEL stay sealed reserve.
  • Carbs — 350 g/day, starch over sugar (fructose feeds uric acid), biggest portions around training.
  • Uric acid 8.2 — first line: hydration 2.5–3 L + vitamin C + citrate. ZYRIK only if >8.5–9 or flare. Never start in an acute flare.
  • Cabergoline — replaced prami (weekly, stronger PRL tool, less D3 texture). PRL baseline draw before first dose; taper on exit, never cold-stop. ICD net: NAC + memantine + citicoline.
  • Not in stack — P5P (multi covers B6), NACET, milk thistle, lemborexant.
